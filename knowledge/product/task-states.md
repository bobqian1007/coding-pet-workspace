# 状态与桌宠行为

| 状态 | 桌宠行为 | 通知行为 | MVP |
| --- | --- | --- | --- |
| `IDLE` | 睡觉 | 无 | 可作为默认状态 |
| `RUNNING` | 工作动画 | 无 | 后续准确接入 |
| `WAITING_USER` | 提醒动画 | 需要输入 | 后续 |
| `APPROVAL_REQUIRED` | 警觉动画 | 需要授权 | 后续 |
| `COMPLETED` | 庆祝动画 | 任务完成 | 核心验收状态 |
| `ERROR` | 出错动画 | 异常提醒 | 后续 |

## 语义约束

- Codex `agent-turn-complete` 只证明一个 Agent 轮次完成，不证明整个用户任务或会话结束。
- 不能仅靠完成通知判断任务启动、等待输入或等待授权。
- 后续引入新事件来源时，应先在 Adapter 中映射，再进入统一状态管理器；UI 不处理平台特有语义。
